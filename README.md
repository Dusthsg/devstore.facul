# DevStore

Loja online com dashboard administrativo — projeto acadêmico em equipe, construído com metodologias ágeis (Scrum + XP).

## Estrutura do projeto

```
devstore/
├── backend/     → API, banco de dados, regras de negócio
├── frontend/    → Interface web (React)
└── .github/     → Templates de colaboração (PR, etc.)
```

## Como rodar o projeto

Cada pasta (`backend/`, `frontend/`) tem seu próprio README com instruções de como configurar e rodar. Este projeto ainda não tem código implementado — esta é a estrutura inicial para o time começar a construir.
