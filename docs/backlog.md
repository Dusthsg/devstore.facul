# Backlog — Fase 1 (Construção da Base)

> Histórias de usuário para a equipe priorizar na Sprint Planning. Não há indicação de "como" implementar — isso é decisão do time durante o sprint.
>
> Formato: **Como [papel], quero [ação], para [motivo]**

Marquem aqui o time responsável e o status conforme forem trabalhando. Sintam-se livres para adicionar, remover ou reescrever histórias — isso também é backlog refinement.

---

## Autenticação

- [ ] Como visitante, quero me cadastrar com nome, e-mail e senha, para poder comprar na loja.
- [ ] Como usuário cadastrado, quero fazer login com e-mail e senha, para acessar minha conta.
- [ ] Como usuário logado, quero permanecer autenticado ao navegar pela loja, para não precisar logar a cada página.
- [ ] Como usuário logado, quero fazer logout, para encerrar minha sessão com segurança.

## Produtos

- [ ] Como visitante, quero ver a lista de produtos disponíveis, para escolher o que comprar.
- [ ] Como visitante, quero ver os detalhes de um produto (nome, descrição, preço, imagem), para decidir se vou comprá-lo.
- [ ] Como administrador, quero cadastrar um novo produto, para disponibilizá-lo na loja.
- [ ] Como administrador, quero editar um produto existente, para corrigir ou atualizar suas informações.
- [ ] Como administrador, quero remover um produto, para tirá-lo de circulação.

## Carrinho

- [ ] Como usuário logado, quero adicionar um produto ao carrinho, para comprá-lo depois.
- [ ] Como usuário logado, quero ver os itens do meu carrinho, para revisar antes de finalizar a compra.
- [ ] Como usuário logado, quero alterar a quantidade de um item no carrinho, para ajustar minha compra.
- [ ] Como usuário logado, quero remover um item do carrinho, para desistir daquele produto.

## Pedidos

- [ ] Como usuário logado, quero finalizar a compra dos itens do carrinho, para concluir meu pedido.
- [ ] Como usuário logado, quero ver a confirmação do meu pedido após finalizar a compra, para saber que deu certo.

## Dashboard (esqueleto inicial)

- [ ] Como administrador, quero acessar uma área de dashboard separada da loja, para gerenciar o sistema.

---

## Fora do escopo da Fase 1 (guardar para a Fase 2)

Histórias que dependem de autorização por papel (roles), segurança mais aprofundada, estoque, pagamentos e relatórios pertencem à Fase 2 — não tragam para o backlog inicial. Consultem o [guia de metodologia](./guia-projeto-loja-online.md) para os critérios de saída de cada fase.
